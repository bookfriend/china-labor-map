# 中国劳工争议分布图

基于人社部统计公报、省级人社厅公报、最高人民法院典型案例等**公开信源**的中国各省劳动争议数据可视化。

🌐 在线访问：https://china-labor-map.pages.dev

## 数据亮点

- 2025 年全国劳动争议「调解组织 + 仲裁机构共办理」**454.3 万件**，2017→2025 年增长约 173%
- 已核实 3 省仲裁数字：北京 14.3 万件（2025，口径A）、广东 92.8 万件（2024，口径B）、四川 17.5 万件（2025，口径B）
- 10 省有官方典型案例 / 法院阶段数据；28 省暂无公开可核实数据（页面如实标注，未做估算）

## 口径说明

人社部统计有两个不可混用的口径：

- **口径A「仲裁机构立案受理」**：2024 年全国 168.6 万件
- **口径B「调解组织和仲裁机构共办理」**：2025 年全国 454.3 万件

本页面北京数据为口径A，广东、四川为口径B。地图按「数据可得性」分层着色，不按案件数量着色，避免跨口径误导对比。

## 数据来源

全部 22 项参考文献见页面「数据来源」一节，每个数字与案例均附原始出处链接。
